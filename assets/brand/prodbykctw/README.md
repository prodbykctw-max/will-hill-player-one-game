# prodbyKCTW logo — animated

Supplied by prodbyKCTW on 2026-08-11. Kept in the repo under the rule in
CLAUDE.md: **if losing the file means the work cannot be rebuilt, commit it.**
This is a brand mark, it was not made here, and it cannot be regenerated.

The mark: a brain-shaped Earth (green continents, blue oceans) with a cyan
glow, `prodby` in white and `KCTW` in a green-to-cyan gradient beneath it, over
the tagline **Knowledge Changed The World**.

**The tagline is PAST TENSE — "Changed", not "Change".** Both docs in this repo
had it wrong until the logo arrived and settled it. The acronym still reads
KCTW either way, which is exactly why nobody caught it.
