# tools/

- **`deploy.sh`** — builds via Vite and publishes `dist/` to a freshly-rebuilt `gh-pages` orphan branch. Refuses to run from `gh-pages` or a detached HEAD. Never uses `git add -A` on the deploy branch (see `CLAUDE.md` for why that guardrail exists).
- **`cut_ending_plate.py`** — writes `src/assets/backgrounds/ending-base.webp` from his SHOWTIME plate (853x1843). His painting carries its own title, its own eight stat LABELS and its own RESTART button, so the only edit is emptying the eight placeholder VALUES he drew. A vertical cut cannot do that — his longest label ends at x728 and his longest value starts at x696 — so it works per row, finding the widest gap in that row's ink and erasing outward from it, filled with a per-row median of his own near-black brick. Re-derives itself from the image, so a future pass with different placeholders needs no edit here. Prints the row baselines and value edge that `src/render/ending.js` positions against.
- **`crop_entry_plate.py`** — the ONE thing that writes `src/assets/ui/contest-entry.webp`. Crops his ENTER CONTEST cabinet from 853x1844 to 853x992 at a black rule he painted (y991 is the darkest row on the plate; y993 is the bevel under it), composites a green tick over the silver knob to replace the SAVE button the crop removes, and prints the fraction remap — `v' = v * 1844 / 992`, horizontals unchanged. The tick is his own red CANCEL disc: cross inpainted out with a per-RADIUS median so his concentric rings survive, redrawn at his measured stroke width in his measured ink, R and G swapped. `--preview` writes contact sheets. ⚠️ Run it AFTER `edit_enter_button.py` and BEFORE `cut_glow_glyphs.py entry`; nothing else may write that webp.
- **`compose_player_sheet.py`** — packs Will Hill's 9 in-scope animations (see `docs/GDD.md` → "Character asset pipeline") from `assets/raw-sprites/will-hill/` (git-ignored raw AutoSprite export) into `src/assets/sprites/will-hill.webp` + `will-hill.atlas.json`, a single game-ready spritesheet Vite hashes and bundles. Trims each frame to the shared union bounding box and saves as quality-92 WebP (0.86MB vs. an untrimmed lossless PNG's 3.8MB, no visible quality loss). Analogous to the Jandé project's `tools/compose_bosses.py`. Requires Pillow (`pip install pillow`); re-run it any time the raw source frames change:
  ```bash
  python tools/compose_player_sheet.py
  ```
